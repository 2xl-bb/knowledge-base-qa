# 课程笔记知识库（RAG 问答）

一个基于 **RAG（检索增强生成）** 的个人知识库问答应用：把课程笔记建成知识库，向它提问时，它会先检索最相关的笔记片段，再让大模型**只根据笔记内容**回答，并标注答案引用了哪些笔记。

## 功能

- **命令行对话**：`python chat.py "你好"`，可以直接跟大模型聊天
- **笔记建库**：读取 `notes/` 里的 `.txt` / `.md` / `.pdf` 文件，自动切块并向量化，存成 `kb.json`
- **命令行问答**：`python ask.py "什么是朴素贝叶斯？"`，展示检索到的段落和相似度，再给出基于笔记的回答
- **网页版问答**：Streamlit 界面，侧边栏显示知识库概况，回答附带"引用了哪些笔记"（可折叠查看原文）

## 技术栈

- Python 3
- 智谱 GLM（`glm-4-flash`，对话模型，免费）
- 硅基流动（`BAAI/bge-m3`，向量模型，免费）
- Streamlit（网页界面）

全部使用免费额度，零成本运行。

## 目录结构

```
knowledge-base-qa/
├── chat.py          # 对话脚本（智谱 glm-4-flash）
├── build_kb.py      # 建库：笔记切块 + 向量化，输出 kb.json
├── ask.py           # 命令行问答（检索增强生成）
├── app.py           # Streamlit 网页版，带引用展示
├── common.py        # 公共工具：读 key、调 API、算向量、算相似度
├── notes/           # 课程笔记目录（支持 .txt / .md / .pdf）
└── .gitignore       # 忽略 key 文件、kb.json 等
```

## 快速开始

### 1. 环境准备

需要 Python 3.10+，然后安装 Streamlit：

```
pip install streamlit
```

### 2. 获取两个 API Key（都免费）

| 用途 | 平台 | 文件 |
| ---- | ---- | ---- |
| 对话模型 | [智谱 open.bigmodel.cn](https://open.bigmodel.cn) | `key.txt` |
| 向量模型 | [硅基流动 siliconflow.cn](https://siliconflow.cn) | `key_sf.txt` |

注册后在控制台创建 API Key，分别粘贴到项目目录下的 `key.txt` 和 `key_sf.txt`（新建文件即可）。

> 两个 key 文件已加入 `.gitignore`，**不会被提交到 GitHub**，请勿将 key 发到网上。

### 3. 建库

把自己的课程笔记（`.txt` / `.md` / `.pdf`）放进 `notes/` 文件夹，然后运行：

```
python build_kb.py
```

看到 `知识库已保存到 kb.json` 即成功。**以后笔记更新了，重新运行一次即可。**

> PDF 说明：课件、论文这类有文字层的 PDF 会**逐页**入库（回答会精确标注出自哪一页）；如果是扫描件（图片拍出来的 PDF，提取不到文字），建库时会提示跳过，那种需要 OCR 工具先转成文字。

### 4. 提问

```
python ask.py "朴素贝叶斯为什么适合垃圾邮件过滤？"
```

### 5. 网页版

```
streamlit run app.py
```

浏览器自动打开 `http://localhost:8501`，即可在网页上提问。

## 工作原理（RAG）

1. **建库**：把笔记切成长度合适的小块，每块用向量模型转成向量，存入 `kb.json`
2. **检索**：提问时把问题也转成向量，计算问题与每个笔记块的相似度，取最相关的几块
3. **增强**：把这几块笔记原文和问题一起交给大模型
4. **生成**：大模型只根据笔记内容回答，回答有依据、可追溯、不乱编

**为什么不把所有笔记直接塞给模型？** 因为模型上下文长度有限、API 按 token 计费，而且不相关的段落会干扰回答质量。检索的价值就是把"最相关的片段"精准捞出来，这是 RAG 的核心思想。
